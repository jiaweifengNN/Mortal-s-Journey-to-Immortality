# Mortal-s-Journey-to-Immortality · 凡人修仙传

> 凡人之躯，亦可行仙路 —— 我的全生命周期记录项目。

一个以《凡人修仙传》修仙风格可视化的个人人生记录站：纯静态网页，无需构建，浏览器直接打开 `index.html` 即可。

## 卷目结构

| 卷 | 名称 | 内容 | 状态 |
|----|------|------|------|
| 卷一 | 修行日志 | 人生日志（每日干了啥、吃了啥），2025 乙巳年 · 炼气期 起 | 持续录入 |
| 卷二 | 灵膳录 | 美食地图 / 探店记录（按武昌·汉口·汉阳·异地分坊市，含后备名单） | 持续录入 |
| 卷三 | 肉身境 | 身体状态与注意事项 | 封印中，待启 |

## 页面特性

- 修仙风格：朱砂·鎏金·黛青·月白 暗色古风配色，灵气粒子、境界阶梯（炼气 → 筑基 → 结丹 → 元婴）
- 修行日志：按年（炼气期/筑基期）筛选、按月分卷、全文搜索（"以神识探查"）、灵膳标签
- 灵膳录：按区域筛选、按品阶分级（上品·熟客 / 中品·一晤 / 机缘·未至 / 凶地·勿入）、搜索
- 零依赖：原生 HTML/CSS/JS，无任何外部库与网络请求

## 文件结构

```
├── index.html   # 页面与交互逻辑
└── data.js      # 数据源（人生日志 + 美食地图）
```

## 数据更新

数据源为本地维护的文档（人生日志 docx、武汉美食地图 xlsx），更新后重新生成 `data.js` 即可：

- `logs[]`：`{ d: 日期, e: 事件, f: [灵膳], r: 路线 }`
- `eaten[]`：`{ n: 店名, t: 类型, s: 是否吃过, reg: 区域, area: 具体区域, note: 备注, date: 日期 }`
- `backup[]`：后备名单（还没吃但想吃 / 还没吃但避雷）

卷三"肉身境"解封后，在 `data.js` 中扩展 `body` 字段并在 `index.html` 中替换封印区即可。
